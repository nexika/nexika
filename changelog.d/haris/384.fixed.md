A program haris trusts by name (git, python3, npm, make ...) is no longer trusted when it would run from the project or a temp folder instead of the usual place: `PATH=/tmp/bin git push`, `env -P /tmp/bin git status`, `export PATH=tools:$PATH; git status` and `/tmp/bin/git status` now ask. Virtual environments, node_modules/.bin, gradlew and mvnw, and your own tool folders (~/.local/bin, ~/.cargo/bin) stay quiet.
