Python code that imports the project's own modules is judged with those modules: `PYTHONPATH=py python3 -c "import wipe"` and `python3 -m py.wipe` are refused like `python3 py/wipe.py`. PYTHONPATH, PYTHONSTARTUP, PYTHONHOME and PYTHONUSERBASE pointing at a temp folder now ask, and writing a .pth or sitecustomize.py into site-packages asks. `PYTHONPATH=src pytest` stays quiet.
