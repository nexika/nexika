Inline Python that runs a file as code (`exec(open('/tmp/t.py').read())`, `exec(compile(...))`, `runpy.run_path`) is judged by the file's text instead of always asking, when haris may read it: a regular file, not a link and not under a linked folder, in the project or the temporary folder, at most 64 KB. The exact part the code runs is judged (`.split(...)[0]` and the like). A file that changed since haris read it earlier in the session, or that something in the same command may change first, still asks; the session keeps only its path, size and times. `python FILE` (up to 16 KB) is now refused when the file does something refused in every profile, such as deleting your home folder.
