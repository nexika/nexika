A source checkout of haris, mizan or tabib in a git repo (the Nexika repo) is now ordinary project code: Claude can import and run it. Only the installed copies under ~/.claude/plugins and the plugins' data stay protected. Running a checkout's haris hook by hand is refused when it would use your real haris data (no HARIS_HOME or HOME of its own), and asked about when its data folder is only known when it runs.
