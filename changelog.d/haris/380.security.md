Variables passed through `env` (`env GIT_DIR=... git push`, also with `-i`, `-u`, `-S`, `-a`, or behind `nice`, `timeout`, `nohup`, `command`, `exec`) are now judged exactly like `GIT_DIR=... git push`: a push of another repository asks instead of passing. Variables given to a shell (`GIT_DIR=... bash -c '...'`) count inside it too.
