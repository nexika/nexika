lawha check compares every icon between the English and Arabic renders. Icons that show direction (arrows, chevrons, send, reply, undo and redo, log-out, alignment, lists, text arrows such as →) must point the other way in Arabic, and media controls, clocks, ticks and logos must not be mirrored. Names come from lucide, tabler, Font Awesome, Bootstrap Icons, Material ligatures, sprites and file names. An app that swaps the icon itself in RTL counts as mirrored, and Tailwind 4's rotate and scale properties are read as well as transform.
